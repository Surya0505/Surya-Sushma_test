# Sushma & Surya Wedding Website

Files: `index.html` and `couple-photo.jpg`. Keep them in the same folder. The site includes all three events in chronological order, the supplied couple photo, family names, and QR codes generated from the exact Maps URLs.

## Preview locally
Open `index.html` in a modern browser.

## Publish with GitHub Pages
Create a GitHub repository, upload both files to the repository root, then open Settings → Pages and select Deploy from a branch, branch `main`, folder `/ (root)`. After publishing, GitHub will provide the public URL.
